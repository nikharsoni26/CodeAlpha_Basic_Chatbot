# CodeAlpha Python Internship

## Project: Basic Chatbot

This is a simple rule-based chatbot built using Python.

### Features
- Greets the user
- Answers "How are you?"
- Tells its name
- Responds to "Thank you"
- Exits when the user types "bye"

### Concepts Used
- Python functions
- If-elif-else statements
- While loop
- User input and output
- String methods

### How to Run
Run chatbot.py using Python.
